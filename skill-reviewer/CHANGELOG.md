# Changelog

All notable changes to Skill Reviewer will be documented in this file.

## [1.0.0] - 2026-09-14

### Added

- Core review workflow
- Review-before-rewrite principle
- Severity classification using `Critical`, `Important`, and `Improvement`
- Review criteria for:
  - Purpose
  - Triggering
  - Instructions
  - Workflow
  - Consistency
  - Constraints
  - Edge cases
  - Maintainability
  - Release readiness

- Version comparison between skill revisions
- Regression risk analysis
- Structured review output
- Evidence-based findings
- Deterministic release status classification:
  - `Ready`
  - `Ready with Improvements`
  - `Needs Changes`
  - `Blocked`

- Release readiness evaluation
- English canonical documentation
- Portuguese documentation
