# Skill Reviewer

Skill Reviewer is an AI skill designed to review other AI skills before publication or versioning.

It evaluates skill definitions similarly to a code review, identifying structural problems, ambiguous instructions, conflicting rules, maintainability risks, regressions, and release blockers.

The goal is to improve skill quality without automatically redesigning or rewriting the original behavior.

## What It Does

Skill Reviewer can help you:

- Review a `SKILL.md`
- Validate a skill before publishing it
- Prepare a skill for a new release
- Identify contradictory or ambiguous instructions
- Detect duplicated or unnecessary rules
- Evaluate workflow consistency
- Identify maintainability problems
- Review constraints and edge cases
- Compare two versions of a skill
- Detect possible regressions
- Evaluate release readiness
- Prioritize required fixes before optional improvements
